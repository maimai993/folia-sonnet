# 影视模块（Video Immersive）

Folia 桌面版的「影视」入口：从登录窗口左栏的平台列表进入，打开一个与 Folia 本体同色系的影视工作台
（3D 海报卡片流 + 详情页 + 播放器）。播放层按 PotPlayer / mpv / YouTube / IINA 的通行键位重新实现，
并把 TVBox 的配置与站点协议接进来。

## 入口

- 登录窗口左栏「影视」行（`__video__`）→ 影视工作台。
- 设置 → 连接与集成 → 影视：填 TVBox 配置地址；留空则用内置源。

## 播放器能力

| 能力 | 说明 |
| --- | --- |
| 单击画面 | 暂停 / 继续（240ms 内再点一次算双击） |
| 双击画面 | 中间：全屏；左侧：后退 10 秒；右侧：前进 10 秒 |
| Esc | 逐级返回：快捷键表 → 右键菜单 → 右侧面板 → 退出全屏 → 回到选集 |
| 控制条 | 3 秒自动淡出；暂停、菜单、面板、音量条、快捷键表在场时常亮 |
| 右键菜单 | 播放/暂停、打开›、全屏、画中画、截图、画面›、字幕›、声音›、播放›、循环、A-B、快退/快进、上下集、媒体信息 |
| 画质增强 | 菜单里一键开关：对比度 1.08×、饱和度 1.16×、亮度 1.03×，叠在用户滑条之上 |
| A-B 循环 | `B` 设 A 点，再按 `B` 设 B 点；进度条上以琥珀色区段标出 |
| 断点续播 | 每 5 秒记一次位置（`folia-video-pos:` 前缀），下次从上次位置继续 |
| 自动下一集 | 播完 5 秒倒计时自动续播，可「立即播放」或「停在这儿」 |
| 画面 | 缩放三态（contain / cover / fill）、旋转 90°、镜像、亮度/对比度/饱和度、一键重置 |
| 其它 | 画中画、截图（存下载目录，跨域失败如实提示）、逐帧、倍速、字幕搜索 |

## 键位

与 PotPlayer / mpv 的通行约定一致，`F1` 可随时调出完整一览。

| 键 | 作用 |
| --- | --- |
| `Space` / 单击 | 暂停 / 继续 |
| `←` / `→` | 后退 / 前进 5 秒（`Shift` 为 30 秒） |
| `↑` / `↓` | 音量 ±5 |
| `Enter` / `F` | 全屏切换 |
| `Esc` | 逐级返回 |
| `PgUp` / `PgDn` | 上一集 / 下一集 |
| `,` / `.` | 逐帧后退 / 前进（暂停时） |
| `[` / `]` | 倍速 ∓10% |
| `{` / `}` | 倍速减半 / 加倍 |
| `Backspace` | 恢复 1× |
| `L` | 切换循环模式（单集 / 列表 / 关） |
| `B` | A-B 循环打点 |
| `0`–`9` | 跳到片长的 0%–90% |
| `M` | 静音 |
| `滚轮` | 音量 |
| `F1` | 快捷键一览 |

## TVBox 兼容

影视源按 TVBox 客户端的协议发请求，配置也按 TVBox 的形态解包：

- **请求头**：`User-Agent: okhttp/3.15`、`Accept: application/json, text/plain, */*`、`Accept-Language: zh-CN,zh;q=0.9`。
  多数影视配置与站点接口按 UA 识别客户端，浏览器 UA 会被 403 或返回空配置。
- **配置形态**：明文 JSON → 宽松 JSON（去 `//` 注释、尾随逗号、单引号键）→ 整段 base64
  （兼容 url-safe 的 `-_` 与缺位补 `=`）→ 图片藏配置（取图中最长 base64 串）。
- **多仓入口**：`{"urls":[{"url","name"}]}` 会并发拉取前 6 个仓库，合并站点；
  键重名加 `@仓库名`，名称前缀 `仓库名·`。
- **站点类型**：`type 0/1`（苹果 CMS XML/JSON 接口）可直接播放；`type 3/4`（csp spider jar /
  远程 spider 服务）需要 Java/Dex 运行环境，本仓库不内置，界面会把这类站点标成「本机不支持」。
- **读不到配置**：不会整页报错，而是退回内置源并在底部提示失败原因。

## 已知限制

- csp（`type 3/4`）站点无法运行：没有 JVM / Dex 运行环境。
- 部分影视站的 `svip` / `share` 线路只给播放网页而非 m3u8，需要先抓页面再播放，目前只提供「用浏览器打开」。
- 字幕搜索走 OpenSubtitles：中文剧名多搜不到，用拼音或英文名可搜。

## 构建

```bash
# 前端（必须带 ELECTRON=true，否则 vite base 变 /，装后卡在启动画面）
ELECTRON=true npx vite build
# Windows 安装包（跳过 appleMusic 预构建；需要 PATH 里有 powershell.exe）
FOLIA_SKIP_WIN_COMPANION=1 npx electron-builder --win nsis
```
