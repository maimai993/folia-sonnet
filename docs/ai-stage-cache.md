# 通用AI视觉缓存

stage包含日夜主题和歌词动画决策，不包含歌词正文或歌曲绝对时间轴。不同来源继续使用各自歌词，只有视觉结果共享。

## 身份与存储

以完整歌名和结构化完整歌手名单建立身份；规范Unicode、大小写、空白和括号格式，保留Live、Remix等版本文字。不拆组合名、不以歌手子集或模糊歌名兜底，缺歌手保持旧精确键兼容。

完整stage按云服务命名空间存入IndexedDB，保存当前、上一版和远端修订。本地先用、后台检查更新，检查间隔60秒；网络失败不让已有结果失效。缓存最多256项，保护当前、预取窗口与选定回退版本。分析数据分类可清理stage缓存，不计作已缓存音频歌曲数。

手动重生成仅替换本机选择；自定义提示、导入或覆盖歌词不覆盖公共版。云端新版保存后仅在发起播放轮次仍有效时应用，并提供绑定具体版本的撤销操作。回退只影响本机。

## 调度

主题、导演和预取共用单例入口。模型请求最多一个运行、一个最高优先等待目标：手动当前歌、自动当前歌、下一首依次优先，自动请求稳定停留1.2秒。共享消费者独立取消，底层Promise真正结束前不释放生成槽。

后续十首只查询并保存缓存，并发2；预计结束或混音交接前45秒，只为紧邻下一首补缺生成。沿实际队列顺序，未知后续洗牌不自行推测。旧播放轮次、同歌歌词替换、较旧恢复及旧通知均无权覆盖新选择。

## 服务端

新可选接口`/api/ai-stage`公开读和原子补缺，ETag支持304。授权替换要求Bearer SYNC_TOKEN与baseRevision，有限历史最多10份。来源关联为客户端自报，不视为身份验证或覆盖授权。完整主题、注册模式、参数范围和UTF-8 64KiB限制统一校验。旧缓存保留读取，公开PUT不再任意覆盖现存记录。

先部署兼容服务端，再更新客户端。旧数据需单独只读预演和受控迁移；本功能不会自动扫描全平台或推断艺人别名，不需要模型重生成既有内容。

## 验证与边界

相关测试覆盖真实React hook提交、IndexedDB版本操作、单生成调度、队列预取和SQLite并发补缺/CAS。Node服务端编译与Worker打包支持共享纯数据契约。

Android现有媒体timeupdate、MotionValue和生命周期用于进度触发；WebView完全冻结时没有独立原生调度保证，锁屏实机仍需验收。没有持久上传重试发件箱、自动跨平台抓取和长期版本管理页面。通知不将生成成功等同于上传确认。
